# Godfrey & Amanda — Wedding App

Private wedding invitation and guest experience app for **Godfrey & Amanda**, Goa — **28 January 2027**.

## First build
- Mobile-first wedding homepage
- Sage, ivory and Amalfi-inspired visual direction
- Wedding day overview
- RSVP entry point
- Explore Goa and Stay & Travel sections
- Installable PWA manifest
